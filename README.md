# 🦷 Dental Patient Manager

A desktop application designed for dental/medical practices to manage patient records, appointments, and practice operations efficiently.

---

## ✨ Features

- ✅ Patient Registration
- ✅ Appointment Scheduling
- ✅ Medical History Tracking
- ✅ Search & Filter
- ✅ Billing Management

---

## 🛠️ Tech Stack

- **Python** — Core language
- **Tkinter** — Desktop GUI
- **SQLite** — Database
